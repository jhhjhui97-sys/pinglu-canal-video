# 平陆运河通航｜30秒朝气版短视频

定位：30秒、9:16竖屏、快节奏、青春向海、重大工程宣传片质感。

## 核心事实
- 平陆运河全长134.2公里
- 按内河Ⅰ级航道建设，可通航5000吨级船舶
- 建设马道、企石、青年三座航运枢纽
- 2026年9月16日正式通航
- 西南地区货物经平陆运河出海，航程可缩短560公里

## 推荐成片风格
开场3秒必须抓人：日出水面 + 船闸开启 + 巨轮破浪，配低频冲击音；中段使用高速航拍、延时、地图线条与数字动效；结尾落在北部湾海面与“向海图强”大字。

## 文件
- `script.md`：30秒旁白与字幕文案
- `storyboard.md`：逐秒分镜
- `subtitles.srt`：可直接导入剪映/PR的字幕
- `assets.md`：素材需求清单
- `render.sh`：FFmpeg快速合成脚本模板

## 素材目录约定
```
assets/
  01_sunrise.mp4
  02_lock_open.mp4
  03_ship.mp4
  04_aerial_canal.mp4
  05_hub.mp4
  06_port.mp4
  07_youth.mp4
  music.mp3
```

将对应镜头放入 `assets/` 后，可根据 `render.sh` 快速生成初版，再在剪映、Premiere 或 Resolve 中做精修。

## 信息来源
- 广西壮族自治区相关公开资料：平陆运河全长134.2公里、内河Ⅰ级、5000吨级船舶、三座航运枢纽。
- 2026年9月16日公开报道：平陆运河正式通航。
